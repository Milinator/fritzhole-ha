# Screenshots

Benötigte Bilder für die README (PNG, Breite ca. 1600–1800 px, keine echten Gerätenamen, IP-/MAC-Adressen oder
privaten Domains – vorher schwärzen oder Testdaten verwenden):

| Datei | Inhalt | verwendet in |
|---|---|---|
| `dashboard-overview.png` | Tab „Übersicht“: Kennzahlen, Verlauf, Top-Listen | README.md, README.en.md (Kopfbereich) |

Optional, falls später eine Galerie gewünscht ist:

| Datei | Inhalt |
|---|---|
| `live-log-context-menu.png` | Live-Protokoll mit geöffnetem Kontextmenü „Erlauben / Sperren“ |
| `dns-filter.png` | Tab „DNS-Filter“ mit Status, Pause und Allowlist/Blocklist |
| `filterlists.png` | Filterlisten mit Status- und Fehleranzeige |

Nach dem Hinzufügen in beiden README-Dateien den markierten HTML-Kommentar (`SCREENSHOT EINFÜGEN` /
`INSERT SCREENSHOT`) durch die darin vorbereitete `<img>`-Zeile ersetzen.
